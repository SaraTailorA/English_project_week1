# Product Cost Calculator

## Description

This project is a simple Python program that calculates the total cost of a product.
It is a beginner-level script that demonstrates how user input, loops, and error handling work in Python.

The program asks the user to enter the name of a product, the price, and the quantity.

## How it works

1. The program asks the user to enter the product name and stores it in a variable.
2. The program asks the user to enter the price and checks if the value is a valid decimal number.
3. If the value is invalid, the program shows an error message and asks for the price again.
4. The program asks the user to enter the quantity and validates that the value is an integer.
5. The program calculates the total cost by multiplying the price and the quantity.
6. The program prints the product information and the final cost in the console.

## Status

> The program is currently running as a basic learning project and is demonstrating how Python handles user input and data validation.
